# Tune library

The tunes the generator knows by name, with the key it uses by default and the ii–V targets it writes lines for. A target in major gets a major ii–V (m7 → 7 → maj7); a minor target gets a minor ii–V (m7♭5 → 7♭9 → m7). Every major tune also gets a one-bar ii–V and the full chain (minor ii–V into ii, then the home ii–V); minor tunes get a one-bar minor ii–V.

Keys follow common fake-book keys. To use another key, pick it in the Key menu and every target moves with it. To use a chart's exact changes, paste them into the Changes box.

To add a tune, add an entry to `tunes.js` (format described at the top of that file).
