# Line templates

Every line on the page comes from one of these templates. Each is written in ABC notation (eighth-note unit) for one specific ii–V, then moved diatonically to the ii–V being practised, so the shapes stay the same and the spelling follows the new key. The engine picks up or down for each transposition so the line stays between G3 and A5 in the original octave (an octave lower by default on the page).

New variations rotates through the pool for each kind of ii–V.

## Major ii–V (one bar per chord: ii | V | I)

**Essential 1** · written for Fm7 → B♭7 → E♭maj7 (key signature E♭)

```
"ii"FAce gfec|"V"=BAFD _B,DFA|"I"G4 z4|]
```

**Fm9 arpeggio** up and back down. B♮ (the ♭9) slides into a B♭7 arpeggio, and **A♭ → G** is the guide-tone resolution into E♭.

**Essential 2** · written for B♭m7 → E♭7 → A♭maj7 (key signature E♭)

```
"ii"FAB_d fe_dB|"V"GEGB _dfe_d|"I"c4 z4|]
```

B♭m7 arpeggio with the 11th, then E♭7 with its 9th (F). **D♭ → C** is the guide tone from the 7th of E♭7 to the 3rd of A♭maj7.

**Essential 3** · written for Dm7 → G7 → Cmaj7 (key signature C)

```
"ii"dcAF EFAc|"V"Bdfe dBGF|"I"E4 z4|]
```

Dm9 down from the root and back up from the 9th. C → B links the 7th of Dm7 to the 3rd of G7, and **F → E** does the same into Cmaj7.

**Bebop 1** · written for Fm7 → B♭7♭9 → E♭maj7 (key signature E♭)

```
"ii"zceg fedc|"V"=Bdfa g_gfd|"I"e2B2 d4|]
```

Starts on the and of 1. Over B♭7♭9 it outlines a **B°7** arpeggio (the ♭9 sound), then runs G–G♭–F–D chromatically and steps up to E♭.

**Bebop 2** · written for B♭m7 → E♭7♭9 → A♭maj7 (key signature E♭)

```
"ii"fe_dc BAGF|"V"=EGB_d =e_dB=B|"I"c2e2 g4|]
```

B♭ dorian down from F, an **E°7** arpeggio for E♭7♭9, then B♭–B♮ chromatically into C.

**Bebop 3** · written for Dm7 → G7♭9 → Cmaj7 (key signature C)

```
"ii"zAce gfed|"V"c=Bdf _agfd|"I"e2c2 G4|]
```

Up the top of Dm9 and down the scale, then a C → B approach into a **B°7** arpeggio (the ♭9 sound), and D steps up to **E, the 3rd of Cmaj7**.

## Minor ii–V (one bar per chord: iiø | V7♭9 | i)

**Essential 1** · written for Gm7♭5 → C7♭9 → Fm7 (key signature E♭)

```
"ii"GB_df e_dBG|"V"=EGB_d cBAG|"I"A4 z4|]
```

Gm7♭5 arpeggio, then **E♮**, the 3rd of C7. C–B♭–A♭–G is the phrygian-dominant sound, and G rises to A♭, the 3rd of Fm.

**Essential 2** · written for Dm7♭5 → G7♭9 → Cm7 (key signature E♭)

```
"ii"FAcf edcA|"V"=Bdfa gfd=B|"I"c4 z4|]
```

Dm7♭5 arpeggio, then a B°7 arpeggio over G7♭9. The **leading tone B♮** resolves to C.

**Essential 3** · written for Dm7♭5 → G7♭9 → Cm7 (key signature C)

```
"ii"dc_AF DF_Ac|"V"=BG_AB df_ed|"I"c4 z4|]
```

Dm7♭5 down and back up. Over G7♭9 the line circles the 3rd (B–G–A♭–B), climbs to the 7th and lands on **C** through the ♭13 (E♭) and the 5th (D).

**Bebop 1** · written for Gm7♭5 → C7♭9 → Fm7 (key signature E♭)

```
"ii"z_dfa gf_dB|"V"AG=EG B_dcB|"I"A2c2 F4|]
```

A B♭m7 shape over Gm7♭5 gives the half-diminished color. The A♭ on beat 1 of C7♭9 is the **♭13**, and the line lands on A♭ again in Fm.

**Bebop 2** · written for Dm7♭5 → G7♭9 → Cm7 (key signature E♭)

```
"ii"zdfa gfed|"V"c=Bdf agfd|"I"e4 z4|]
```

Locrian run from D back down to D, a C–B♮ approach into the ♭9 arpeggio, and D steps up to **E♭, the 3rd of Cm**.

**Bebop 3** · written for Dm7♭5 → G7♭9 → Cm7 (key signature C)

```
"ii"zF_Ac _edc_A|"V"G=Bdf _agfd|"I"_e2c2 G4|]
```

Starts on the and of 1 with Dm7♭5 and its ♭9 (E♭), runs up G7♭9 to the ♭9 (A♭) and back down, and D rises to **E♭, the 3rd of Cm**.

## One-bar major ii–V (ii V | I)

**Essential 1** · written for Fm7 → B♭7 → E♭maj7 (key signature E♭)

```
"ii"A2e2 "V"d2A2|"I"G4 z4|]
```

Guide tones only: **A♭ and E♭** (3rd and 7th of Fm7), **D and A♭** (3rd and 7th of B♭7), resolving to G.

**Essential 2** · written for Dm7 → G7 → Cmaj7 (key signature C)

```
"ii"FAce "V"dBGF|"I"E4 z4|]
```

Dm9 up from the 3rd, G7 down from the 5th, and the 7th (F) falls to **E**.

**Bebop 1** · written for Fm7 → B♭7♭9 → E♭maj7 (key signature E♭)

```
"ii"fedc "V"=Bdfa|"I"g4 z4|]
```

The classic shape: F–E♭–D–C down, **B°7** up, and A♭ falls to G on the downbeat.

**Bebop 2** · written for Dm7 → G7♭9 → Cmaj7 (key signature C)

```
"ii"fedc "V"=B_AGF|"I"E4 z4|]
```

A straight run down: Dm7 from F, then B–A♭–G–F over G7♭9 (3rd, ♭9, root, 7th), and F resolves to **E**.

## One-bar minor ii–V (iiø V7♭9 | i)

**Essential 1** · written for Dm7♭5 → G7♭9 → Cm7 (key signature C)

```
"ii"F2c2 "V"=B2F2|"I"_E4 z4|]
```

Guide tones only: **F and C** (3rd and 7th of Dm7♭5), **B and F** (3rd and 7th of G7♭9), resolving to E♭.

**Bebop 1** · written for Dm7♭5 → G7♭9 → Cm7 (key signature C)

```
"ii"dc_AF "V"=Bdf_a|"I"g4 z4|]
```

Down Dm7♭5 from the root, up a **B°7** arpeggio for the ♭9 sound, and A♭ falls to G, the 5th of Cm.

## Full chain (iiø/ii | V/ii | ii | V | I)

**Bebop 1** · written for Gm7♭5 → C7♭9 → Fm7 → B♭7 → E♭maj7 (key signature E♭)

```
"a"zGB_d fagf|"b"=e_dBG =EGB_d|"c"cBAG FAce|"d"dfag _gfdA|"e"G2B2 d4|]
```

Each bar ends a half or whole step from a chord tone of the next: F → E♮, D♭ → C, E♭ → D, A♭ → G.
